Bakery Sales Data Analysis Using Python

Analyzed bakery sales transactions using Python. Performed data cleaning and visualization to identify best-selling products, busiest days, and sales trends.

Tools Used

Python, Pandas, NumPy, Matplotlib, Seaborn

Project Insights

  • Most Selling Product: Coffee
  • Least Selling Product: Chicken Sandwich
  • Busiest Day: Saturday
  • Peak Shopping Hour: 11 AM
